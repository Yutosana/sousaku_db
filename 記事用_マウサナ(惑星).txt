# マウサナ

**マウサナ**は、恒星アナを中心とするアナ星系の第三惑星である。地球よりやや大きな岩石惑星であり、地表には広大な海洋と大陸が存在する。酸素を豊富に含む大気を持ち、多様な生命が生息する。

第二惑星ロエメウとは同一の公転軌道を共有しており、互いに約60°の角度を保ちながら恒星アナの周囲を公転する。この特殊な軌道配置は、アナ星系を特徴づける要素の一つとなっている。

## 1. 軌道と自転

### 1.1 公転軌道

マウサナは恒星アナから平均0.953 AU（約1億4,260万km）の距離を公転している。

公転周期は343.2地球日、軌道離心率は0.02であり、比較的円に近い楕円軌道を持つ。

主星アナは太陽の約98%の質量と約89%の光度を持つG5V型主系列星である。マウサナは太陽系の地球より主星に近い位置を公転しているが、アナの光度が太陽より低いため、受け取る恒星放射は地球とほぼ同程度となっている。

### 1.2 自転と季節

マウサナの自転周期は24時間32分であり、地球の自転周期よりやや長い。

自転軸は公転面に対して19.2°傾斜しており、この傾斜によって季節変化が生じる。地球の約23.4°と比較すると傾斜角が小さく、その他の条件が同等であれば、日射量の季節変化は地球よりやや穏やかになる。

### 1.3 ロエメウとの共軌道関係

マウサナは第二惑星ロエメウと同一の軌道長半径を持ち、1:1平均運動共鳴の関係にある。

両惑星は平均約60°の位相差を保って公転しており、恒星アナと両惑星を結ぶ位置関係は、おおむね正三角形に近い配置となっている。

| 項目 | 値 |
|---|---|
| 共軌道惑星 | ロエメウ |
| 共鳴比 | 1:1 |
| 平均位相差 | 約60° |
| 平均相互距離 | 約0.953 AU |
| 相互距離 | 約1億4,260万km |
| 光通信の片道所要時間 | 約7分55秒 |
| 光通信の往復所要時間 | 約15分50秒 |

マウサナから見たロエメウは、恒星アナから約60°離れた位置に見える。そのため、ロエメウは主として明け方または夕方の空に現れ、深夜の空に高く昇ることは基本的にない。

ロエメウの見かけの直径は約22.5秒角であり、肉眼では点状の明るい天体として認識される。一方、望遠鏡を用いれば、約75%が照らされた円盤状の姿を観測できる。

見かけの明るさはおおむね−3〜−4等級と見積もられ、マウサナの夜明けや夕暮れの空で目立つ天体となっている。

## 2. 物理的性質

### 2.1 大きさと質量

マウサナの直径は約14,742kmであり、地球の約1.157倍の半径を持つ。

質量は地球の1.436倍であるが、平均密度は5.11g/cm³と地球よりやや低い。このため、地球より大きな惑星でありながら、表面重力は地球の約1.073倍にとどまっている。

地表での重力加速度は約10.5m/s²に相当する。

### 2.2 内部構造

マウサナは地球と同様に、金属を主体とする核、岩石質のマントル、および地殻から構成される地球型惑星である。

内部構造は地球と大きく異ならないと考えられており、地球と同様の地質活動や鉱床形成が可能な構造を持つ。

また、惑星の平均密度が地球よりやや低いことは、地表付近の金属資源が乏しいことを意味しない。金属元素の分布や火成活動、熱水活動などによって、地殻中には利用可能な鉱物資源が形成されている。

### 2.3 磁場

マウサナは地球と大きく異ならない性質の惑星磁場を持つ。

磁場は惑星内部の活動に由来するものであり、周囲には磁気圏が形成されている。磁気圏は恒星アナから到来する荷電粒子と相互作用し、惑星の宇宙環境に影響を与えている。

## 3. 大気

### 3.1 大気の特徴

マウサナは窒素と酸素を主成分とする比較的高密度の大気を持つ。

地表の平均大気圧は1,486hPaであり、地球の海面標準気圧の約1.47倍に相当する。

大気中の酸素濃度は26.3%で、地球より高い。さらに大気圧も高いため、酸素分圧は約391hPaに達する。

### 3.2 大気組成

| 成分 | 体積比 |
|---|---:|
| 窒素（N₂） | 67.5% |
| 酸素（O₂） | 26.3% |
| アルゴン（Ar） | 5.5% |
| 二酸化炭素（CO₂） | 0.12% |
| 水蒸気（H₂O） | 平均0.55% |
| その他 | 0.03% |
| **合計** | **100%** |

その他の微量成分には、希ガス、メタン、オゾンなどが含まれる。

水蒸気の濃度は気温や地域、気象条件によって変化するため、上記の値は全球平均的な組成を示している。

### 3.3 地球大気との比較

## 4. 表面環境

### 4.1 気温と気候

マウサナの全球平均表面温度は22℃であり、地球より温暖な環境を持つ。

恒星アナから受け取る放射エネルギーは地球とほぼ同程度であるが、大気組成や大気圧、海陸分布などの違いによって、独自の気候が形成されている。

自転軸傾斜が地球より小さいため、日射の季節変化は比較的穏やかである。ただし、実際の地域ごとの気温や降水量は、緯度、標高、海流、地形などによって大きく異なる。

詳細は「マウサナの気候」を参照。

### 4.2 海洋と陸地

マウサナの表面は約68%が海洋、約32%が陸地によって占められている。

地球と同様に海洋と大陸が共存しており、海洋は惑星全体の熱輸送や水循環に重要な役割を果たしている。

| 表面構成 | 割合 |
|---|---:|
| 海洋 | 68% |
| 陸地 | 32% |

詳細な大陸配置、主要海洋、山脈、河川などについては「マウサナの地理」を参照。

### 4.3 地質環境

マウサナの地表には岩石質の大陸と海洋底が存在する。

地球と同様の内部構造を持ち、火成活動、熱水活動、地殻変動などによる地形形成や鉱床形成が行われている。

詳細は「マウサナの地質」を参照。

## 5. 衛星

### 5.1 ポマヤ

マウサナには、ポマヤと呼ばれる大型の岩石衛星が存在する。

ポマヤは直径約3,927kmであり、地球の月よりやや大きい。マウサナから平均約473,000kmの距離を公転している。

### 5.2 マウサナから見たポマヤ

ポマヤの平均見かけ直径は約0.476°であり、地球から見た月に近い大きさで観測される。

最大視等級は約−12.6等とされ、満月に相当する位相では夜空を明るく照らす。

ポマヤの朔望月は約34.2地球日であり、マウサナの地表からは周期的な満ち欠けを観測できる。

また、ポマヤの重力はマウサナの海洋に潮汐を生じさせる要因の一つとなっている。

詳細は「ポマヤ」を参照。

## 6. 生物圏

マウサナには独自の生命圏が成立しており、海洋と陸上の双方に多様な生物が生息している。

マウサナの生物は、地球生命と同様にDNAを遺伝情報の保存に、RNAを遺伝情報の発現などに利用する。一方、遺伝暗号や標準アミノ酸の構成には地球生命と異なる特徴がある。

生物相には乳腺動物分枝や羽毛動物分枝などが存在し、地球とは異なる進化史に基づく生態系が形成されている。

詳細は「マウサナの生物相」を参照。

## 7. 知的生命体と文明

マウサナには、知的生命体であるマウサナ人が存在する。

マウサナ人は長い歴史の中で複数の文明を形成し、国家、宗教、文化、科学技術を発展させてきた。

惑星の自然環境や物理的条件は、マウサナ人の生活や文明の発達に影響を与えている。また、共軌道惑星ロエメウや衛星ポマヤは、天文学的な観測対象であると同時に、文化や宇宙開発とも関係する天体である。

詳細は「マウサナ人」「マウサナの歴史」などを参照。
